# Sistema de Adoção de Animais Domésticos

> Aplicação web desenvolvida para gerenciar o cadastro, triagem e processo de adoção de animais resgatados de situações de abandono e maus-tratos.

## Objetivo
Este sistema tem como objetivo cadastrar e apresentar animais que ficarão visíveis para potenciais adotantes. A plataforma centraliza o histórico de saúde e as características físicas dos animais resgatados, além disso mantém o controle do fluxo de adoção, garantindo que cada pet encontre um lar compatível com suas necessidades.

## Características do Projeto

Este projeto foi desenvolvido com o objetivo acadêmico de consolidar na prática os fundamentos da **Programação Orientada a Objetos (POO)** utilizando a linguagem **Java**.

Os principais conceitos e práticas explorados na arquitetura do sistema incluem:

* **Fundamentos e Modelagem:** Definição de classes, instâncias, inicialização de objetos, troca de mensagens e tipos abstratos de dados.
* **Pilares da POO:** Aplicação prática de Abstração, Encapsulamento, Herança e Polimorfismo.
* **Arquitetura e Relacionamentos:** Uso de interfaces (contratos) e composição para estruturar o domínio do sistema.
* **Boas Práticas e Projeto:** Noções de modelagem UML (Diagrama de Classes) e aplicação introdutória de Padrões de Projeto (*Design Patterns*).
